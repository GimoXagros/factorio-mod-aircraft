# Aircraft

[Aircraft 원본 저장소](https://github.com/Stifling-Bossness/Aircraft)에서 가져온 Factorio 모드 소스입니다. 항공기 4종을 추가합니다.

[info.json](info.json)에 기록된 모드 버전은 `1.5.2`, 대상 게임 버전은 Factorio `0.16`입니다. 필수 의존성은 `base >= 0.16.0`이며 Bob 모드 의존성은 선택 사항입니다. 전체 목록은 manifest를 확인하세요.

이 소스를 설치할 때는 `info.json`이 바로 들어 있는 `Aircraft_1.5.2` 폴더를 Factorio의 사용자 `mods` 폴더에 둡니다. 저장소 ZIP의 바깥 폴더 이름을 그대로 사용하지 마세요. 다른 Factorio 버전과의 호환성은 이 manifest에 선언되어 있지 않습니다.

제작자 표기는 SuicidalKid(원본 Eldwen)입니다. 변경 내역은 [changelog.txt](changelog.txt), 원본 안내는 [포럼](https://forums.factorio.com/viewtopic.php?f=120&t=18714)을 확인하세요.
